# Chatbot App 🤖

A chatbot interface built with React.js while learning component-based 
architecture and state management.

## Features
- Chat UI with user and robot messages
- useState for message management
- Component-based architecture
- Built with React + Vite

## Tech Used
- React.js
- Vite
- JavaScript (ES6+)
- CSS3
- HTML5

## Project Structure
src/
├── components/
│ ├── ChatInput.jsx
│ └── ChatMessages.jsx
├── App.jsx
└── App.css
